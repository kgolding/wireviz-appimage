# WireViz AppImage builder

Packages [WireViz](https://github.com/wireviz/WireViz) — a Python CLI tool
for documenting cables and wiring harnesses — as a portable AppImage that
runs on most Linux distros without needing Python or Graphviz installed
system-wide.

## Why this exists

I always have trouble git WireViz working, with Ubuntu complaining about that I should use apt install etc.... So I got Claude to help me create this repoe to generate an AppImage version of WireViz that "just works".
